# SKVERNA — сборка 0.1 «Мидгард»

## Как запустить для проверки
1. Установите Node.js (https://nodejs.org, версия LTS).
2. Запустите `start.bat` (первый раз он скачает Electron, нужен интернет).

## Как собрать установщик (.exe)
- Вариант 1: запустите `build.bat`. Готовые `SKVERNA Setup 0.1.0.exe` (установщик) и portable-версия появятся в папке `dist`.
- Вариант 2 (без установки Node.js): загрузите эту папку в репозиторий GitHub, откройте вкладку Actions → «Build Windows installer» → Run workflow. Готовый .exe скачивается из Artifacts.

## Управление (меняется в Настройках)
WASD — ходьба · ЛКМ или J — удар и добыча (ЛКМ целится курсором) · ПКМ или F — поставить блок / использовать предмет · Пробел — рывок · E — действие (алтарь, станции, кровать; зажать — копать землю) · Tab — инвентарь и создание · Esc — пауза · 1–9 — слоты.
Геймпад: левый стик — ход, правый — прицел.

## Алтари боссов
В биомах стоят алтари (пирамида, цитадель, замок, святилище). Подойдите и нажмите E. На мини-карте красные точки — алтари.

## Шрифт
Положите файл шрифта в `assets/fonts/skverna.ttf` (или `skverna.woff2`) — он подхватится автоматически. Пока используется запасной готический шрифт.
